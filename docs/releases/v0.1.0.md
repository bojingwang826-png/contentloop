# ContentLoop v0.1.0 — Portfolio Demo

ContentLoop v0.1.0 is the first documented portfolio milestone for the full
game-content creation workflow.

## Highlights

- Turn an idea, public webpage, or screenshot into five differentiated topics.
- Build a research brief, three viewpoints, and a strictly seven-page outline.
- Edit and lock individual pages, then ask AI to rewrite the current page from
  the user's latest title and instructions.
- Render 1080×1440 visual pages with dynamic layouts and export PNG or ZIP.
- Generate matching publishing copy and optionally write approved drafts to a
  local Obsidian pending-review directory.
- Keep model keys server-side and validate AI output against explicit field,
  fact, source, and asset boundaries.

## Try it

the product flow without a model key.

```bash
npm ci

npm test
npm run build
```

## Known limitations

- The first complete content template targets *Battle of Golden Spatula*.
- OCR for dense, low-resolution icon labels can still require manual review.
- The public demo does not include accounts, team workspaces, cloud draft sync,
  automated social publishing, or billing.
- Game rankings, strength assessments, and season values are not guaranteed to
  be real-time unless a verified source is supplied.
