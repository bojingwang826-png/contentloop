# 开发进展｜导出空文件修复 v1.2

## 用户反馈

- 点击图片或 ZIP 下载后，文件没有可见内容。

## 原因判断

- 原实现完成异步 Canvas 渲染后，立即通过临时 Blob 地址模拟点击并触发下载。
- 部分浏览器会限制失去直接用户手势的异步下载；临时地址又很快被释放，存在得到空文件或下载失败的风险。
- 原界面没有在下载前展示最终图片和文件大小，用户无法判断生成阶段是否已经有内容。

## 本次修复

- 图片按钮从“直接下载”改为“先生成并预览”：生成完成后在导出页展示真实 PNG 缩略图。
- 每张图片显示页码和实际 KB 数，并提供独立、常驻的“下载 PNG”链接。
- 七页全部生成后展示七张缩略图，再提供“下载已检查的七页 ZIP”链接和 ZIP 实际大小。
- 缩略图可以点击放大查看，下载前能确认文字、背景和装备图标均已出现。
- PNG 小于 10 KB 时直接判定为空并停止交付；ZIP 小于七张图片原始数据总量时判定为内容不完整。
- 新的 Blob 地址会保留到重新生成或关闭页面，不再在异步下载刚触发后立即释放。

## 验证结果

- 单页第 2 页生成结果：1080×1440，约 1113 KB，页面内可见缩略图和直接下载链接。
- 七页均生成成功，每页约 1066～1113 KB，七页 ZIP 约 7743 KB。
- ZIP 结构测试会逐项读取七个本地文件头，确认七个中文文件名和每个文件的数据长度都大于 0。
- 自动测试、静态检查和生产构建通过。

## 新的使用方式

1. 点击“生成当前第 X 页 PNG”或“生成七页 ZIP 发布包”。
2. 等待页面出现“图片已生成并检查到内容”。
3. 先查看缩略图；需要时点击图片放大。
4. 单页点击“下载 PNG”，七页点击“下载已检查的七页 ZIP”。
