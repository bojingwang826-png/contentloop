# 开发进展｜高清 PNG 与七页 ZIP v1.1

## 本次完成

- 七页编辑预览和高清导出共用同一套页面渲染模型，标题、说明、装备卡、页码、系列名与账号名不再分别维护。
- 建立 1080×1440 的 3:4 高清画布渲染器，覆盖封面、基础合成、装备讲解和判断口诀四类页面。
- 第 2 页把两件散件与合成结果都换成 Riot 客户端独立 PNG；第 3～6 页继续使用同一批官方清晰图标。
- 图片生成前等待浏览器字体和本页全部装备图标加载；图标缺失或加载失败时停止下载并显示原因，不使用文字占位冒充正式图标。
- 导出页支持 1～7 页切换，可单独下载当前页 PNG。
- 支持依次生成七张 PNG，并在浏览器本地打包为一个 ZIP 发布包；最终图片不会上传服务器。
- 导出过程显示“正在生成第几页”和完成／失败反馈，生成期间按钮自动禁用，防止重复点击。
- 若存在未处理的观点冲突，PNG 和 ZIP 按钮保持禁用；结构化 JSON 草稿仍可下载检查。

## 文件规格

- 单页尺寸：1080×1440，比例 3:4。
- 单页命名：`铲友装备课01-第01页.png` 到 `铲友装备课01-第07页.png`。
- 发布包命名：`铲友装备课01-七页发布包.zip`。
- 压缩包内容：七张按页码排序的 PNG，文件名保留中文和两位页码。

## 关键产品决策

- 页面内容先转成统一渲染模型，屏幕预览和 Canvas 高清成图都从该模型读取，降低编辑内容与导出内容不一致的风险。
- 装备图标只接受已映射的官方独立 PNG；正式成图不使用截图裁切、AI 重绘或文字缩写占位。
- 黄色待核验项暂不阻止资料整理型图片生成，但页面文案不能冒充当前版本强度结论；观点直接冲突继续作为硬阻塞。
- ZIP 使用浏览器本地生成，不引入外部服务，也不需要上传用户最终成图。

## 验证结果

- 43 项自动测试全部通过，新增覆盖共用渲染模型、全角／半角配方解析、PNG 文件命名、CRC32 与七文件 ZIP 结构。
- 静态检查通过：34 个必需文件、19 项规则。
- 生产构建通过。
- 浏览器实际完成“下载当前第 2 页 PNG”和“生成七页 PNG → 打包 ZIP → 下载”两条流程。
- 导出页已显示 1080×1440 规格、当前页选择、进度状态和观点冲突阻塞说明。

## 当前边界

- 当前为首套“铲友装备课”深紫金色模板，还没有 6～8 套背景和更多内容模板。
- ZIP 当前只包含七张 PNG；结构化 JSON、发布正文与标签仍分别下载／复制，后续可合并为完整发布包。
- 文字溢出目前通过固定版式与行数限制控制，尚未加入导出前逐页问题清单和一键跳转修复。

## 下一步建议

- 继续 Phase C 的“导出前逐页质检”：展示七页缩略图，自动检查文字溢出、缺图和低清素材；有问题时可跳回对应页面，修复后只重生成失败页。
