# 开发进展｜装备卡排序 v0.7

## 本次完成

- 第 3～6 页的每张装备卡增加“上移”和“下移”按钮，不依赖拖拽，手机和键盘都能操作。
- 第一次调整后显示“人工顺序已保护”；AI 重写只修改文案，不会重新排列装备卡。
- 支持一键恢复系统默认顺序。
- 卡片移动时，已保留的适用场景和选择判断会跟随对应装备移动，不会串到别的卡片。
- 排序动作进入全流程版本历史，可撤销、重做和恢复。
- `manualOrder` 随本地草稿和结构化 JSON 导出保存。

## 数据约定

- Phase A 原型使用装备名称数组保存 `manualOrder`。
- 正式 Schema 迁移后改用稳定的装备 ID，交互语义不变。
- `manualOrder` 为空表示使用系统默认顺序；非空表示用户明确调整过，需要被保护。

## 交互约束

- 上移、下移按钮触控高度至少 44px，并提供明确文字和键盘焦点。
- 第一张不能继续上移，最后一张不能继续下移；禁用状态需清楚可见。
- 页面锁定后不能调整或恢复顺序。

## 验收重点

- 调整顺序后，预览区同步更新。
- AI 重写后顺序保持不变，同时未保留的文案仍可正常变化。
- 撤销后能回到调整前顺序，重做后能恢复人工顺序。
- 375px 手机上不出现横向滚动。

## 下一步建议

- “整篇重写影响范围”预览已在 [[开发进展-整篇重写影响预览-v0.8]] 完成。
