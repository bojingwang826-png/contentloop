# 导出正文 v0.3

## 本轮反馈

1. 第五步的小红书正文需要更有平台网感，并可适量使用 Emoji。
2. 正文需要像第四步页面编辑一样，支持输入一句 AI 建议后重新生成。

## 已实现

- 默认正文改为“痛点开场 → 三点拆解 → 一句口诀 → 事实边界 → 自然互动”的短段落结构。
- Emoji 只用作视觉停顿，不用作按钮或结构图标，也不每段堆叠。
- 正文改为可直接编辑，修改后自动保存在本机，并显示字符数。
- 新增“给 AI 一句修改建议”和“按建议重新生成正文”按钮。
- 当前离线 Demo 支持：网感、详细、精简、新手化、互动、Emoji 增减、克制语气和“把 A 改成 B”。
- 未识别具体意图时执行通用口语化重组，并明确提示，不把建议原文写入正文。
- “复制正文”和 JSON 草稿导出均使用用户修改后的最新正文。

## 风格依据

- 参考小红书公开主题规范：鼓励细化主题、结合表情符号表达，同时避免无意义信息、虚假夸张和恶意模仿。
- 结合游戏攻略内容的搜索属性，正文优先服务新手痛点、可复现步骤和快速查阅。

## 验证结果

- 自动测试：14 项全部通过。
- 实际交互：空建议时按钮明确禁用；输入“精简一点，不要 emoji”后生成更短且无 Emoji 的正文。
- 375px 手机宽度：无横向滚动，正文输入区和重写按钮完整可用。
- 浏览器控制台：无错误或警告。

## 后续建议

- 接入真实模型后，将离线意图规则替换为结构化 AI 输出，但继续保留事实边界与用户手改内容保护。
- 增加正文历史版本、一键撤销和多版本对比。
