# 开发进展：动态研究卡与七页大纲 v1.7

日期：2026-08-20

## 本次完成

把首页生成的临时候选选题真正接入后续创作流程：

1. 用户从 3 个候选方向中选择一个，点击“用这个方向生成研究卡”。
2. 系统把选题、事实边界和来源关系复制成正式创作项目；候选卡本身仍是临时素材。
3. 研究页解释为什么值得做、为什么现在适合做，并给出正好 3 个差异化观点。
4. 每个观点单独显示适用人群、内容风险、事实引用和来源引用；争议与待补问题分开呈现。
5. 用户确认观点后，系统生成正好 7 页的小红书图文大纲。
6. 每页包含页面角色、标题、摘要、2～4 个内容要点、事实引用数量和素材需求。
7. 用户可以确认并保存动态大纲，整个正式项目进入本地保存和全流程版本保护。

## AI 安全边界

- 动态研究卡只能引用输入理解阶段已经建立的事实 ID 与来源 ID。
- 七页大纲只能引用研究卡白名单事实；模型若返回不存在的事实 ID，整次结果被拒绝。
- 资料不足时只生成判断方法、结构或待补素材，不自动补写版本强度、胜率、登场率、爆料、个人实测或结果承诺。
- 研究卡和大纲使用严格 JSON Schema；在线模型返回无效结构时保留旧内容。
- 研究与大纲复用已核验边界，不重复开启网页检索，避免额外成本和来源漂移。

## 演示模式

没有配置在线模型时，免费演示模式也能完整体验这条链路。装备类候选会生成三种观点：

- 先认散件，再理解功能；
- 按英雄定位分装备；
- 按功能寻找平替。

七页结构为：封面 → 新手问题 → 基础框架 → 主 C 判断 → 前排与辅助 → 功能平替 → 收藏口诀。
