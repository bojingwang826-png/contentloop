# 开发进展：真实阵容与站位专用版式 v2.3

## 本次完成

1. 修复官方方形头像被横幅裁切、放大和显示不全的问题。官方素材使用完整显示策略，不再强制铺满横幅。
2. 阵容与羁绊主题的大纲会自动加入真实成员、羁绊效果、基础建议站位和低费到高费过渡，不再只生成通用判断文字。
3. 新增真实成员页：显示英雄官方头像、名称、费用、羁绊与前后排职责；七名英雄时最后一张自动居中。
4. 新增基础站位页：按英雄射程与职责分成后排、灵活位和前排，并明确提示实战需根据对手换边、防切入和范围伤害调整。
5. 封面会用当前选题的真实英雄头像组成阵容图，不再把单个方形头像拉伸成模糊横幅。
6. 第三步大纲提前展示真实英雄名称、费用、羁绊档位和站位摘要，用户编辑后仍能带入第四步。
7. 第四步的配图状态会正确标记为“官方素材＋文字”，预览与最终导出继续使用同一套 3:4 手机画布。

## 数据与事实边界

- 英雄名称、费用、羁绊、射程和头像来自当前赛季 Riot Data Dragon 与 CommunityDragon 数据。
- 站位属于根据射程和职责生成的基础建议，不标为官方唯一答案，也不冒充实时胜率阵容。
- 羁绊页面展示真实成员和客户端羁绊说明；涉及强度排行、胜率和补丁环境时仍需单独核验。
