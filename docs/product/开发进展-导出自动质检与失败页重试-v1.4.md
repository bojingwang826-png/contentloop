# 开发进展｜导出自动质检与失败页重试 v1.4

## 目标

让用户在下载前就知道每张图片是否完整，避免再次出现正文空白、文字被截断、图标缺失或七页中只有部分页面生成成功却无法恢复的问题。

## 本次实现

- 每页生成时同步建立质检记录，检查标题、补充说明、装备讲解、合成路径和判断口诀是否超出允许行数。
- 检查正文坐标是否有效、内容是否越过 3:4 图片安全区、应有内容块是否完整绘制。
- 检查官方装备图标的预期数量和实际加载数量；缺图直接标为生成失败。
- 每张缩略图显示“质检通过”或“需调整文字”，问题卡会写清第几页、哪个字段需要处理。
- 文字过长时保留单页预览，但不生成七页 ZIP，并提供“返回编辑”直接定位到问题页。
- 单页生成失败时保留其他成功页面，提供“单独重试”；七页全部通过后自动重新打包 ZIP。
- ZIP 打包自身失败时显示“重新打包”，不再出现无效的“第 0 页失败”。
- 调整合成树卡片布局，为较长的装备名预留更多宽度，正常内容不再被误判截断。

## 交互原则

- 问题提示紧挨对应导出结果，不让用户到别处寻找原因。
- 黄色表示图片已生成但文字可能被省略；红色表示页面不能可靠导出。
- 恢复操作使用明确动词：“返回编辑”“单独重试”“重新打包”。
- 七页 ZIP 只在七页均通过时出现，避免把已知有问题的图片误当成正式发布包。

## 验证结果

- 正常样例实测生成 7 张 1080×1440 PNG，七页标题、正文、官方图标和安全区全部通过，ZIP 下载正常出现。
- 第 2 页较长装备名“海克斯科技枪刃”完成排版修正并通过质检。
- 隔离测试中故意输入超长装备讲解后，系统识别到“第 3 页／无尽之刃适用场景超过 2 行”，并准确返回第 3 页编辑界面。
- 47 项自动测试、静态检查和生产构建全部通过。

## 当前阶段结论

Phase C 的高清导出闭环已完成：可预览、可下载、可自动检查、可定位修改，也能在局部失败时恢复。下一步进入 AI 适配层，但保留本地演示能力、人工确认和事实边界。
