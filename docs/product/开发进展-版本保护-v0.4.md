# 开发进展｜版本保护 v0.4

> 本文记录最初只覆盖编辑页的版本；全流程升级见 [[开发进展-全流程版本保护-v0.5]]。

## 本次完成

- 在编辑页增加“版本保护”区域，默认只展示必要状态，历史记录按需展开。
- AI 重写当前页前自动保存完整七页快照。
- 支持手动保存当前版本、撤销、重做和从历史列表定点恢复。
- 版本快照同时保留七页内容、当前页位置、锁页状态和素材引用。
- 最近 20 个自动历史版本随草稿保存在浏览器本机；手动存档单独长期保留，刷新页面后仍可恢复。
- 为版本历史补充领域测试和移动端响应式布局。

## 使用方法

1. 在编辑页点击“保存当前版本”，建立一个清楚的起点。
2. 输入 AI 修改建议并重写页面；系统会在修改前再次自动存档。
3. 不满意时点击“撤销”；需要返回时点击“重做”。
4. 展开“查看历史版本”，可恢复到指定时间点。

## 仍待完成的 Phase B 内容

- 用户手改字段标记为“已保留”，AI 重写默认不覆盖。
- 装备卡上移／下移和人工顺序保护。
- 整体重写时逐页展示“保留／重写”影响范围。
- 后续迁移到 IndexedDB，并为手动存档增加自定义名称与管理能力。
