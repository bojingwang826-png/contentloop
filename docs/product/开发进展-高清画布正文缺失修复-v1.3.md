# 开发进展｜高清画布正文缺失修复 v1.3

## 用户反馈

- 下载后的 PNG 有背景、页眉和页脚，但第 2～7 页正文为空。
- 大标题显示成白色小方块，封面也只有部分固定位置元素。

## 根因

高清 Canvas 标题排版同时存在两个参数错误：

1. 标题绘制时漏传最大宽度，`78` 被错误当成标题宽度，中文标题被拆成多行并以 2 像素行距叠成白块。
2. 文本绘制函数返回的是“可见行数”，后续却读取 `.length`，导致正文起始坐标成为 `NaN`，第 2～7 页卡片无法绘制。

## 本次修复

- 恢复标题可用宽度为 952 像素、行高 78 像素、最多 2 行。
- 正文坐标直接使用标题与副标题的数字行数计算，不再读取不存在的 `.length`。
- 把标题布局抽成可测试配置，防止以后因位置参数漏传再次出现白块。
- 保留 v1.2 的“生成后先预览再下载”机制，方便下载前逐页目视确认。

## 验证结果

- 真实导出页面已生成第 1～7 页，七页均可见标题、正文卡片和官方装备图标。
- 单页文件约 842～1086 KB，七页 ZIP 约 6414 KB。
- 页面显示“图片已生成并检查到内容”，七张缩略图均通过目视检查。
- 45 项自动测试、静态检查和生产构建全部通过。

## 用户现在的操作

刷新导出页后重新点击“生成七页 ZIP 发布包”，看到七张正常缩略图后，再点击“下载已检查的七页 ZIP”。旧页面里已经生成的 Blob 文件不会自动变成新版本，需要重新生成。
