# 开发进展｜观点影响与冲突阻塞 v0.9

## 本次完成

- 点击其他主要观点后不再立刻覆盖草稿，而是先生成七页影响清单。
- 每页分为“可以保留、建议重写、直接冲突”，同时说明原因、预计变化字段和已有保护项。
- 普通建议重写页允许逐页选择“保留原页／按新观点重写”；直接冲突页必须按新观点重写。
- 锁定的直接冲突页不会被覆盖，系统会保留冲突记录，并在研究页持续提示。
- 导出检查会单独列出每个观点冲突，并阻止正式图片导出；结构化 JSON 草稿仍可下载排查。
- 观点切换前自动建立全流程版本点，一次撤销即可恢复原观点、七页内容和冲突状态。

## 关键产品决策

- “改变文章观点”是高风险操作，必须先解释影响再执行，不能把它做成普通单选按钮。
- 一致页默认保留；建议重写页由用户决定；直接矛盾不能被“保留原页”掩盖。
- 页面锁定权高于观点重写权。遇到锁定冲突时允许保存新观点，但必须阻止正式交付，避免静默产出自相矛盾的内容。
- 影响预览属于临时分析，不写入长期草稿；只有确认后的观点和未解决冲突会持久化。
- 状态同时使用文字、图标和颜色，主要操作按钮保持至少 44px 点击高度，方便手机使用。

## 验证结果

- 36 项自动测试全部通过，覆盖观点分类、逐页决定、锁定冲突、解锁处理、字段保护和撤销恢复。
- 静态检查和生产构建通过。
- 实际走通“锁定第 2 页 → 切换观点 → 导出阻塞 → 撤销 → 解锁恢复”。
- 目视检查确认三类状态层级清晰，直接冲突不依赖颜色单独表达。
