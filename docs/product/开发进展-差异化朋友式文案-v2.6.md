# 开发进展：差异化朋友式文案 v2.6

## 本次目标

- 清除七页图文中反复出现的万能句和统一收尾。
- 每个小节根据真实对象、运营阶段或局面生成独立内容。
- 语气更接近熟悉游戏的朋友分享，并保留适量小红书攻略感。

## 已完成

### 按内容生成，不再按模板补句

生成器会分别识别并处理：

- 前期留牌与稳血；
- 中期衔接与换牌收益；
- 后期高费核心与阵容上限；
- 主 C 启动、前排承伤和功能位补缺；
- 装备功能、经济止损、来牌数量与同行压力；
- 站位换边、羁绊档位、转阵信号和版本核验。

每类内容都有独立的判断条件、行动建议和实战提醒，不再统一追加“结合当前来牌复核”等万能句。

### 真实阵容成员文案

- 后排、前排和灵活位分别说明不同职责。
- 每名英雄的提醒会结合英雄名称、费用、羁绊和位置生成。
- 同一站位的英雄也不会复用完全相同的说明。

### 页内与跨页去重

- 新增整套七页文案去重检查。
- 同页和跨页出现完全重复的正文、提醒或选择建议时，会按当前页主题重新组织。
- 在线 AI 的大纲和改写要求同步增加具体性、自然口吻与反模板约束。

### 旧草稿升级

- 动态页面版本升级至第 4 版。
- 未锁定页面会自动使用新的生成文案。
- 已锁定页面和用户保留字段继续保持原内容，不会被静默覆盖。
