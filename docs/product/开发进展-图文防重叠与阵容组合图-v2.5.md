# 开发进展：图文防重叠与阵容组合图 v2.5

## 本次目标

- 解决英雄图片与正文相互覆盖的问题。
- 让信息较多的正文卡片按内容增加高度，避免文字被截断。
- 让结尾页优先展示当前阵容的组合视觉图，并保持图片比例。
- 对第 2 至第 7 页进行统一的间距和安全区自查。

## 已完成

### 成员页

- 英雄头像、名称、费用与正文采用独立的纵向安全区。
- 缩小头像占位并增加正文起始间距，避免正文进入图片区。
- 成员卡高度会结合成员数量与可用画布空间动态计算。

### 正文页

- 左图右文布局的正文区域随页面剩余空间增高。
- 正文最多显示行数与卡片高度同步调整，减少内容被提前截断。
- 页脚仍保留固定安全距离，长文不会压住页码和账号信息。

### 结尾页

- 有真实阵容数据时，使用多名当前阵容英雄组成横向组合图。
- 每张图片保持原始比例，以裁切填充方式覆盖对应区域，不做拉伸压缩。
- 没有阵容成员数据时，回退为与主题相关的游戏横幅，避免出现无关图片。

## 验证结果

- 自动测试：114 项全部通过。
- 生产构建：通过。
- 浏览器逐页预览：正文卡、图片区、页脚安全区均未发现新的重叠。
- 第四步预览继续与第五步导出共用同一套画布渲染，因此预览与最终 PNG 保持一致。
