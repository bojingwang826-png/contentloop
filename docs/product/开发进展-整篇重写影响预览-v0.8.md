# 开发进展｜整篇重写影响预览 v0.8

## 本次完成

- 编辑页新增“整篇智能修改”，用户先输入一句整篇建议，再预览影响范围，不会直接改动草稿。
- 系统逐页展示“会修改／已保护／不受影响”，并列出预计变化字段和当前保护项。
- 锁定页不能勾选；字段级保留和人工装备顺序会在影响清单中明确提示。
- 默认只勾选真正受影响的页面，用户可取消任意一页后再确认。
- 分析后若页面内容或修改建议发生变化，旧结果立即标为失效并禁止确认。
- 多页修改只建立一个历史版本点，可用一次“撤销”恢复整篇操作前的状态。

## 关键产品决策

- 影响分析是只读模拟，不保存为正式草稿，也不发送无关页面。
- 确认时只修改用户明确勾选的页面；锁定页即使被错误传入，也由领域规则再次拦截。
- 整篇建议仍按语义理解，不会把用户原话直接塞进图片。
- 影响预览放在版本保护下方、逐页编辑器上方，先做整篇决策，再进入局部微调。

## 验证结果

- 31 项自动测试通过，包含只读分析、锁定页、字段保留、人工顺序和选择性重写。
- 静态检查与生产构建通过。
- 实际走通“预览 → 取消一页 → 确认五页 → 一次撤销”。
- 375×812 手机和 812×375 横屏均无横向溢出，操作按钮高度不低于 44px。
