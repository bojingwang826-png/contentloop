# 开发进展：单网址解析与直接研究 v2.1

## 本次决策

取消“至少确认两个不同站点的来源，才允许进入可信研究链”的硬门槛。

从本版本开始：

- 用户提供任意一个公开网页，解析成功后即可直接用于候选选题和研究卡。
- 不再要求第二个站点，也不再要求额外点击“确认可用于研究”。
- 自动解析失败时，用户粘贴至少 20 个字的公开正文片段并保存，也会立即生效。
- 具体赛季数值、英雄强度和版本结论仍需核对网页日期与适用赛季，但这不会阻止系统围绕当前网页继续创作。

## 已实现的流程

1. 在“给工具一点线索”中粘贴网页链接并点击“分析我的输入”。
2. 系统自动读取公开网页标题、作者、发布日期和正文摘要。
3. 解析成功后显示“已解析，可直接使用”。
4. 网页内容进入事实边界，并参与候选选题生成。
5. 用户可以直接点击“用这个方向生成研究卡”。
6. 若网页无法自动读取，来源卡会显示失败原因，并保留“保存并直接使用”的手动补充入口。

## 页面变化

- “独立来源 0/2”改为“正在等待网页解析”或“已解析 N 个来源”。
- 删除“确认可用于研究”“取消确认”按钮。
- 删除“至少确认两个不同站点”的提示。
- 首页说明改为“粘贴公开网页后会自动解析正文，并直接用于候选选题和研究卡”。
- 原有“待第二来源”标签改为“待版本核对”。

## 解析边界与安全

- 只读取公开的 HTTP/HTTPS 文本网页。
- 限制响应体大小、跳转次数和读取时间。
- 拒绝 localhost、内网地址和带账号密码的网址，防止本地网络被错误访问。
- 不支持登录后内容、图片 OCR 和非文本文件；遇到这些情况时改走手动补充。

## 实际验证

使用 `https://tftips.app/zh/items/spatula` 完成验证：

- 成功识别标题：TFTips - 金铲铲 - 装备详情【云顶之弈】。
- 成功提取 700 字以上的公开页面摘要。
- 输入方向自动识别为“新手装备教学”。
- 候选选题明确标记为根据用户提供的网站内容生成。
- 单个来源可直接进入研究卡，研究卡保留原始 URL 和来源事实。
- 页面控制台无错误。

## 质量结果

- 自动化测试：76 项全部通过。
- 静态检查：通过。
- 生产构建：通过。
- 应用内浏览器端到端检查：通过。

## 后续建议

下一步可继续提高网页正文清洗质量：减少导航、页脚和版权声明对摘要的干扰，并针对常见游戏资料站提取装备名称、合成配方、版本号等结构化字段。
