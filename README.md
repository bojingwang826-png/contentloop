# ContentLoop｜游戏内容 AI 增长工作台

面向金铲铲小红书图文创作者的知识库＋创作工具。当前完成 Phase A 匿名样例、Phase B 编辑保护闭环、Phase C 首套高清导出，以及 Phase D 动态内容生成主链路：用户无需注册、无需模型额度、无需连接 Obsidian，就能从一句灵感生成候选题、研究卡、七页大纲和正式可编辑页面，再完成 PNG／ZIP 导出。

## 当前状态

由于本次运行环境阻止下载 npm 依赖，Phase A 先实现为无依赖的可迁移 Web 原型。它保留了明确的领域数据、验证层和页面边界；依赖可用后，可将视图层迁入 Next.js App Router，而无需重写产品流程与样例数据。

## 启动

需要 Node.js 20.9 或更高版本。

```bash
npm run dev
```

浏览器打开 `http://localhost:4173`。

未配置密钥时自动使用免费演示 AI。需要验证在线模型时，只在启动服务的终端设置环境变量，不要把密钥写进浏览器、前端代码或本地草稿：

```powershell
$env:DEEPSEEK_API_KEY="你的密钥"
$env:DEEPSEEK_MODEL="deepseek-v4-flash"
npm run dev
```

## 验证

```bash
npm run check
npm test
npm run build
```

## 已实现

- 五页面路由与进度导航。
- 5 个选题卡和非实时演示榜单。
- 观点选择、可信度状态与来源说明。
- 已确认的七页“铲友装备课01”大纲。
- 第 3～7 页补充适用场景、选择判断、实战提醒，并支持逐条编辑。
- “给 AI 一句建议”按语义修改内容，不把用户指令原样拼进成品图。
- 页面改写、整篇确认后改写和小红书正文重写已统一接入 AI 适配器；没有密钥时走免费演示模式，有密钥时由服务端调用在线模型。
- 首页可以理解一句灵感、公开网页链接和手动补充，先输出事实边界与来源状态，再生成 3 个候选选题；在线模式仅在链接或热点需求出现时启用网页检索。
- 选中的候选题可以继续生成动态研究卡：解释为什么值得做，给出 3 个差异化观点，并单独展示事实、争议、来源与待补问题。
- 确认观点后会生成严格七页大纲，每页包含角色、标题、摘要、2～4 个要点、事实引用和素材需求；越过事实白名单的结果会被拒绝。
- 确认动态大纲后会直接生成正式七页页面并进入第 4 步；标题、说明和第 3～7 页的逐条讲解都能编辑、保留、锁定和按 AI 建议改写。
- 动态页面第 2 页使用已确认的 8 条基础配方；第 3～7 页的装备标识同时接入编辑预览与高清画布，AI 只改文字，不会替换官方图标。
- 动态项目会生成对应的 3 个标题候选、小红书正文和标签；第 5 步不再回退到固定样例文案。
- 动态研究卡与大纲会保存为正式项目状态并进入全流程版本保护；候选卡本身仍是临时素材。
- 演示模式不会假装读取链接正文：地址会被保留为用户来源，相关事实标记为待核验。
- 在线 AI 只能返回预先允许的文字字段，装备名、配方、图标、页面顺序、锁定页和保留字段不会进入可修改范围。
- 在线结果会经过结构与字段白名单检查；失败时自动再试一次，仍失败则保留旧稿并给出可理解提示。
- 演示 AI 不消耗在线额度；在线模式按访客限制调用频率，前端不会接触 API Key。
- 使用 Riot 客户端独立 PNG 资产展示基础装备与常用成装图标，不再使用截图裁切。
- 逐页编辑、锁定、语义改写与本地草稿保存。
- 主标题、说明和逐条讲解可标记“已保留”，AI 重写自动跳过；小红书正文也可单独保护。
- 第 3～6 页装备卡支持上移、下移和恢复系统顺序；人工顺序会随撤销重做、AI 重写与 JSON 导出一起保留。
- 整篇 AI 修改会先展示七页影响范围、变化字段和保护项；用户可取消任意受影响页，再确认批量修改。
- 切换主要观点前会逐页标出“一致／建议重写／直接冲突”；用户可以保留普通页面，直接冲突页必须重写。
- 锁定页若与新观点冲突，系统不会覆盖内容，并在研究页和导出页持续提示，阻止正式图片导出。
- 五个创作步骤共用全流程版本保护，可保存、撤销、重做并恢复到指定历史状态。
- 手动版本支持自定义名称、改名、按五个创作步骤筛选；删除前二次确认，删除后可以撤销。
- 标题、正文、标签复制，以及结构化草稿下载。
- 编辑预览和高清导出共用页面渲染模型；支持 1080×1440 单页 PNG 与七页 ZIP 发布包。
- 高清导出等待官方装备图标加载并显示逐页进度；观点冲突未处理时阻止正式图片导出。
- 图片与 ZIP 先在导出页生成、展示缩略图和实际文件大小，再通过常驻链接下载，避免异步下载得到空文件。
- 导出前自动检查文字截断、正文越界、缺失图标和内容块；问题会精确定位到页面与字段。
- 七页全部通过质检后才提供 ZIP；单页失败不会清空其他成功页面，可直接单独重试。
- 桌面编辑布局和 375px 手机布局。

## 数据声明

项目里的阵容榜单均明确标注为“演示数据，非实时”。装备页用于展示已确认的内容结构，不声称当前赛季数值或推荐强度已经完成双来源核验。
